# 环境安装说明

> 本文件记录 RabbitMQ Demo 所需环境的安装包信息和使用方式。
> 安装包位于项目根目录。

---

## 安装包

| 文件 | 版本 | 大小 | 描述 |
|------|------|------|------|
| `otp_win64_27.3.4.exe` | Erlang/OTP **27.3.4** | 133 MB | Erlang 运行时（RabbitMQ 依赖） |
| `rabbitmq-server-4.3.1.exe` | RabbitMQ **4.3.1** | 23 MB | 消息队列服务端 |

> ⚠️ **兼容性说明**：RabbitMQ 4.3.x 仅支持 Erlang 27.x 及以下版本，不支持 Erlang 28/29。

---

## 安装步骤

### 1. 安装 Erlang

双击 `otp_win64_27.3.4.exe` 安装，默认路径为 `C:\Program Files\Erlang OTP`。

验证安装：

```bash
erl -version
```

预期输出：`Erlang (SMP,ASYNC_THREADS) (BEAM) emulator version 15.2.7`

### 2. 安装 RabbitMQ

双击 `rabbitmq-server-4.3.1.exe` 安装，默认路径为 `C:\Program Files\RabbitMQ Server\rabbitmq_server-4.3.1`。

### 3. 启用管理插件（可选但推荐）

```bash
rabbitmq-plugins enable rabbitmq_management
```

### 4. 启动 RabbitMQ

当前环境无法注册为 Windows 服务，需通过命令行启动。桌面已创建快捷方式 `start_rabbitmq.bat`，或手动执行：

```bash
set ERLANG_HOME=C:\Program Files\Erlang OTP
set RABBITMQ_HOME=C:\Program Files\RabbitMQ Server\rabbitmq_server-4.3.1
set ERL_LIBS=%RABBITMQ_HOME%\plugins
set RABBITMQ_NODENAME=rabbit@localhost
"%ERLANG_HOME%\bin\erl.exe" -noinput -s rabbit boot -boot start_sasl -kernel prevent_overlapping_partitions false
```

## 常见问题

| 问题 | 解决方法 |
|------|---------|
| `erl` 命令找不到 | 将 `C:\Program Files\Erlang OTP\bin` 添加到 PATH |
| AMQP 连接被拒绝 | 确认 RabbitMQ 已启动，端口 5672 正在监听 |
| 管理控制台无法访问 | 先启用插件 `rabbitmq-plugins enable rabbitmq_management`，再重启 RabbitMQ |
| 消息发送后消费者未收到 | 检查 Exchange / Queue / RoutingKey 三者绑定关系是否正确 |
